# Additional Reminder

### Code Submission & Flashing

- We will ask every team to flash your final code on-site immediately before your demo run. 
- Please ensure the flag is set to `demoMode=true`. This is mandatory so your car can receive the activation signal and control data.

### Car Start Procedure 
- You may place your car at the starting point before the timer begins. 
- Your car must stay completely still until the admin starts the timer and the activation signal is sent, i.e. only start when this value `examState.activated` is `true`.

### Parking Slots

- Parkings slots are only used as end points for the Parking Task (Task 3), and will be randomly picked with lucky draw on the demo day.
